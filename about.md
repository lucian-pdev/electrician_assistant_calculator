Pg 174: din calculul rezistentei electrozilor in paralel reiese ca L = 1m trebuie sa foloseasca 7 electrozi in paralel sa ajungi la norma de <= 10 Ohmi pentru priza de paratrasnet/stalp, si este ineficient pentru casnica (4 ohmi) pentru care ii trebuie 17
Cu electrozi de 3m lungime, se ajunge la <= 4 ohmi cu 8 bucati.

pg 175: calcul rezist Solului: rho calculat = (rho masurat) * K (coeficient in functie de umiditate, tabel C pg 175)
rho masurat = ohm * metru

legea lui ohm I=U/R 
rezistente in paralel Re = 1/R1 + 1/R2 + 1/R3
(rho)calculat = rho_masurat (ohm * metru) * K (coeficient de variatie a Rsol in functie de umezeala)

Rpc = (Rv * Ro) / (Rv + Ro)
Rv = rv / (n * uv)
Ro = ro / (n * uo)
h = q + l/2
rv = 0.366 * (rho calculat / l ) * [ log (2l/d) + 0.5 * log((4h+l)/(4h-l))]
ro = 0.366 * (rho calculat / l ) * log ((2l^2)/ b * q)

h = adâncimea până la mijlocul electrodului, "cat de mare vede pamantul acel electrod"

d = diametrul electrodului

l = lungimea electrodului

b = latimea electrodului orizontal/platbandei
